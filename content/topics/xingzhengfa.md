## 一、学科定位与分值
行政法是法考客观题分值大户（约 40–50 分，含行政诉讼、国家赔偿），主观题近年频繁出现（如行政诉讼综合案例）。以《行政法》《行政复议法》（2024 修订）《行政诉讼法》《国家赔偿法》及司法解释为纲。

## 二、体系框架
```
行政法
├─ 总论：行政法原则、行政主体、行政行为一般理论
├─ 行政处罚（2021 处罚法修订）
├─ 行政许可
├─ 行政强制（强制措施+执行）
├─ 行政复议（2024 新法）
├─ 行政诉讼
└─ 国家赔偿
```

## 三、命题特点
- **重行政行为性质识别**：行政处罚 vs 行政许可 vs 行政强制 vs 行政命令。
- **重程序**：告知、说明理由、听证、送达等程序违法点。
- **重复议与诉讼衔接**：复议前置、复议诉讼选择、复议终局。
- **重举证责任**：行政诉讼被告负举证责任（区别于民事诉讼）。

## 四、学习顺序
总论（原则、主体、行为理论）→ 行政处罚 → 行政许可 → 行政强制 → 行政复议 → 行政诉讼 → 国家赔偿。

## 六、典型例题
【例题】市场监管局以甲企业虚假宣传为由罚款 20 万，未告知听证权。甲不服。可如何救济？
【分析】① 处罚程序违法（未告知听证）；② 甲可申请行政复议或提起行政诉讼；③ 多数处罚非复议前置，可选择；④ 诉讼中被告对处罚合法性负举证责任。
