## 一、冲突规范与系属公式
- 冲突规范：指明某涉外民商事关系应适用何国法律的规范（"范围+系属"）。
- **系属公式**：属人法（本国法/住所地法）、物之所在地法、行为地法、当事人选择的法律、法院地法、旗国法、最密切联系地法。
- 冲突规范类型：单边（直接指向某国法）、双边（抽象连接）、重叠适用、选择适用（无条件/有条件）。

## 二、准据法确定与制度
- **反致/转致**：依本国冲突规范指向外国法时，是否包括该外国冲突法（我国原则上不采用反致）。
- **识别**：对事实/法律问题定性（依法院地法识别为原则）。
- **公共秩序保留**：适用外国法将损害我国社会公共利益的，排除适用（我国保留制度）。
- **法律规避**：故意制造连结点规避我国强制性规定的，不发生适用外国法的效力。

## 三、《涉外民事关系法律适用法》重点规则
| 事项 | 准据法 |
|---|---|
| 民事权利能力/行为能力 | 经常居所地法；从事民商活动可适用行为地法 |
| 不动产物权 | 物之所在地法 |
| 动产所有权 | 法律事实发生时物之所在地法 |
| 合同 | 当事人协议选择（最密切联系/特征履行补充）；消费者/劳动者保护有强制规则 |
| 侵权 | 侵权行为地法；共同经常居所地法（优先）；可事后协议选择法院地法 |
| 婚姻缔结 | 一方当事人经常居所地或国籍国法（符合任一即有效） |
| 夫妻人身/财产关系 | 共同经常居所地法 / 共同国籍国法 |
| 法定继承 | 被继承人死亡时经常居所地法；不动产适用不动产所在地法 |
| 遗嘱 | 立遗嘱人经常居所地/国籍国法（能力）；遗嘱方式符合任一所涉国法有效 |
| 国籍冲突 | 有经常居所→经常居所国；无→最密切联系国 |

## 四、外国法查明
- 查明责任：当事人选择适用外国法的，应当提供；法院依职权查明其他情形。
- 无法查明的，适用**中华人民共和国法律**（兜底）。
- 外国法内容由当事人提供或司法协助/专家等途径查明；当事人异议可辩论。

## 五、国际民事诉讼
- **管辖权**：我国法院对涉外案件依民诉法管辖（被告住所地/合同履行地/侵权行为地等）；涉外合同可依协议管辖（与争议有实际联系）。
- **域外送达**：依条约/外交/领事途径、邮寄（受送达国不反对）、电子方式等。
- **司法协助**：外国法院判决承认执行须依条约或互惠；不违反我国法律基本原则/国家主权安全公共利益。

## 六、仲裁
- 涉外仲裁协议可约定外国仲裁机构；裁决依《纽约公约》在缔约国承认执行（我国1987加入，保留"互惠+商事"）。

## 七、法考真题示例
- （2021）侵权法律适用（侵权行为地/共同居所优先）？
- （2020）法定继承不动产适用不动产所在地法（涉外法第31条）？
- （2019）外国法无法查明的兜底适用中国法？

## 八、易错高频
- 我国不采反致（原则上）；公共秩序保留可排除外国法。
- 侵权：共同经常居所地法优先于侵权行为地法。
- 不动产物权/继承不动产均适用不动产所在地法。
- 外国法查不明→适用中国法（兜底）。
