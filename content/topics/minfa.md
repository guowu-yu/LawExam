## 一、学科定位与分值
民法是法考**分值最高、体系最庞大**的实体法。客观题约 60–70 分（含民法、知识产权法相关），主观题必出一道民法综合大案例（常与合同、物权、侵权、担保交叉），占分 20–30 分。备考须投入最多时间。

## 二、《民法典》体系（七编制）
2021年1月1日《民法典》施行，共 7 编 1260 条，取代旧《民法总则》《合同法》《物权法》《婚姻法》《继承法》《侵权责任法》等九部法律：
1. **总则编**（第1–204条）：民事主体、法律行为、代理、诉讼时效
2. **物权编**（第205–462条）：所有权、用益物权、担保物权、占有
3. **合同编**（第463–988条）：通则 + 典型合同 + 准合同（无因管理、不当得利）
4. **人格权编**（第989–1039条）：生命、姓名、肖像、名誉、隐私、个人信息等
5. **婚姻家庭编**（第1040–1118条）：结婚、离婚、夫妻财产、收养
6. **继承编**（第1119–1163条）：法定继承、遗嘱继承、遗赠
7. **侵权责任编**（第1164–1258条）：归责原则、一般侵权、特殊侵权

配套司法解释（必读）：总则编解释、合同编通则解释、担保制度解释、婚姻家庭编解释、继承编解释、侵权编解释等。

## 三、命题特点
- **重请求权基础**：主观题要求"谁得向谁、依据哪条、主张何种权利"。
- **重体系衔接**：一道题常横跨合同效力 + 物权变动 + 担保 + 侵权。
- **重新增修改点**：居住权、保理合同、高空抛物、离婚冷静期、打印遗嘱、自甘风险、好意同乘等。
- **区分原则是灵魂**：合同效力与物权变动分属债权与物权两个层面，必须分别判断。

## 四、学习顺序建议
总则 → 物权（含物权变动、担保） → 合同（通则+典型合同） → 人格权 → 婚姻继承 → 侵权。先搭骨架再填血肉，每学一制度默写"构成要件 + 法律效果 + 反转情形"。

## 五、高分策略
1. 以"请求权基础"为纲，训练"谁向谁、依何规范、主张何权利"。
2. 对比记忆易混概念（如代位权 vs 撤销权、抵押 vs 质押、善意取得 vs 表见代理）。
3. 每编做思维导图，串起"权利—变动—保护—救济"。
4. 真题闭环：近 5 年民法真题反复做，错题回到法条原文。
